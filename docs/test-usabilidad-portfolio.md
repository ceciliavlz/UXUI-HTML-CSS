# Protocolo de usabilidad — portfolio personal

## Objetivo

Comprobar si una persona que visita el portfolio puede identificar el perfil profesional, entender el caso principal y encontrar una vía de contacto sin ayuda.

Esta evaluación es distinta de las pruebas de compra de Casa Petunia que se describen en `caso-estudio.html`.

## Participantes

Invitar al menos a tres personas que se parezcan al público objetivo (reclutamiento, diseño o potenciales clientes). Pedir permiso para tomar notas; no guardar nombres ni datos sensibles. Registrar cada sesión con un código anónimo (`P1`, `P2`, `P3`).

## Guion

1. “Imaginá que llegaste a este portfolio porque estás buscando una diseñadora. Contame qué hace Cecilia y dónde trabaja.”
2. “Encontrá un proyecto y explicame qué problema resolvía y qué decisiones tomó.”
3. “Si quisieras contactarla, ¿qué harías?”
4. En móvil: “Volvé al inicio usando la navegación del sitio.”

No indicar dónde hacer clic ni explicar etiquetas durante las tareas. Registrar si se completa sin ayuda, tiempo aproximado, dudas y comentarios textuales anonimizados.
